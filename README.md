# PayrollSystem

A simple C# Console Application for managing employees and processing payroll.

## Features

* Employee roles using `enum`
* Salary representation using `Money` struct
* Operator overloading for money addition
* Employee inheritance and interfaces
* Salary validation and tax calculation
* Payroll processing using arrays and indexers
* Delegates and events for payment notifications
* Safe user input using `TryParse`
* Exception handling

## Project Structure

The project is developed step by step, with separate Git commits for the main requirements following a specific devised Task.

Documentation and diagrams are available in the `docs` folder.

## Technology

* C#
* .NET Console Application
* Visual Studio
